# Морской бой онлайн

Онлайн-игра для двух игроков. Клиент работает в браузере, сервер синхронизирует ходы через Socket.IO.

## Запуск на Windows

1. Установи Node.js 18 или новее: https://nodejs.org/
2. Открой командную строку в папке проекта.
3. Выполни:

```bash
npm install
npm start
```

4. Открой http://localhost:3000

Чтобы сыграть вдвоём на разных устройствах, проект нужно разместить на хостинге с поддержкой WebSocket, например Render. После публикации отправь второму игроку ссылку и код комнаты.

## Render

- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`

Это первая рабочая версия проекта. Перед публичным использованием проверь игру на двух устройствах.
